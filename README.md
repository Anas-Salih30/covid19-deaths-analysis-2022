# covid19-deaths-analysis-2022
COVID-19 reported deaths analysis in Sudan, Egypt, Kenya, and South Africa (2022)

## Project Overview

This project analyzes reported COVID-19 deaths in Sudan, Egypt, Kenya, and South Africa during 2022.

## Dataset

The dataset contains daily records of weekly reported COVID-19 deaths per million people for four countries during 2022.

## Countries

- Sudan
- Egypt
- Kenya
- South Africa

## Tools

- Microsoft Excel
- GitHub

## Preliminary Analysis

The initial analysis compares the average reported weekly COVID-19 deaths per million people across the four countries and examines monthly trends during 2022.
